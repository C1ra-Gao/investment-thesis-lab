# Agent MVP audit and decisions

Baseline: existing main plus uncommitted M2–M4/V1 work; preserve all existing files.
184 baseline tests passed, 2 private-fixture suites skipped, after permitting local
HTTP sockets. This is not a live provider or public deployment acceptance result.

Reuse M1 immutable sources/artifacts, verified PDF/JSON locators, Decimal lineage
and scope guards; M2 evaluation and conflict history remain unchanged. Existing
Workspace has persistence, manual/model candidate review, limited orchestration,
followup and version comparisons. Web is a vanilla JS Python HTTP app; gateway
isolates per-user SQLite databases behind authentication and HTTPS.

Gaps: Fuyao live adapter intentionally disabled; current model only DeepSeek;
disclosures only one issuer; no settings; manual stepping; no generic live loop.
Deployment files exist but no server/domain/HTTPS deployment has been established.

Implement an additive /research workspace, provider registry, validated structured
model decisions, bounded sequential durable runtime (Clarify/Plan/Execute/Verify/
Revise/Conclude), background worker, explicit errors, editable plans, provenance,
comparison and task branching. No multi-agent architecture or framework migration.
SQLite WAL and one application worker fit the local MVP; Compose
adds loopback-only ports and persistent storage. User explicitly removed public
deployment from scope; existing gateway files remain as prior work. PostgreSQL is deferred until concurrency
needs warrant migration. Credentials are now loaded from server .env/environment
into memory and are not exported; restart reloads environment configuration while
public-disclosure user consent must be renewed. Interrupted tasks require resume.

Provider configuration was moved out of Web forms at the user's request. Settings
GET exposes configuration booleans only, settings POST returns 405, and a separate
consent endpoint accepts only an enabled boolean. Compose loads .env through
env_file; local Python reads .env without shell evaluation. The state workflow and
evidence validation remain independent of configuration transport.

Public SEC XBRL is a separate raw-source contract, never mapped through Fuyao
metadata. Fuyao uses the existing wire contract with new live acquisitions, not
archived-response playback. Partial/unknown provider basis cannot satisfy numeric
claims. Original PDF or SEC facts must validate their own metadata and locators.
