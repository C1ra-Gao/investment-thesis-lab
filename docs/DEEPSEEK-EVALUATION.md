# ThesisLab｜DeepSeek 真实命题拆解评测记录

> 2026-10-14。**真实调用已发生，语义可靠性尚未通过验收。** 本文根据当次开发测试反馈整理；当前未收到六次完整原始输出、逐请求 Token/计费明细或可核验的独立机器评分文件，因此不虚构它们。以下结果为已报告的观察，不是规模化 Benchmark。

## 1. 评测目的与系统分工

ThesisLab 用户输入**陈述式投资主张**，模型生成**候选** Claim Graph、Research Plan、Evidence Tasks 与 Change Conditions，之后由已有 M2 引擎执行结构契约检查并交给研究者确认。通过 JSON 解析**不等于**通过研究契约；通过 Schema **不等于**保留语义或证明金融事实。

使用供应商 DeepSeek 的 `deepseek-flash` 别名；真实响应的模型内部标识尚无已提交的逐次核对记录。密钥通过指定的本地 macOS Keychain 项目临时访问，未向模型发送私有财报、供应商缓存或研究文件。评测素材为以下三条通用公开主张：

1. 「估值回落但基本面未恶化。」（状态／背离）
2. 「某项外部变化将影响产业链利润分配。」（因果／预测）
3. 「盈利改善主要来自主营业务。」（归因）

检查维度：JSON 可解析、M2 契约合法、原文字符索引与限定保留、断言是否完整、逻辑关系、竞争解释、支持／反证任务、未来观察与结论改变条件、AI 建议与用户原主张是否区分。

## 2. 两轮六次真实调用

| 轮次 | 状态／背离 | 因果／预测 | 盈利归因 | 本轮结果 |
|---|---|---|---|---|
| 第一轮（初始提示词） | 契约失败 | 契约失败 | 契约失败 | JSON 3/3，M2 契约 **0/3** |
| 第二轮（修订提示词、附字符索引表） | 契约通过，仍有语义缺陷 | 契约通过，仍有语义缺陷 | 原文索引错误，契约失败 | M2 契约 **2/3**；总真实调用数 **6** |

汇总：已报告两轮各三次真实请求；首轮 JSON 解析 3/3，第二轮通过契约的 2 项也成功产生可检结构。**六次合计契约通过 2/6**。这不是模型可靠通过率的统计估计，也不能算作 2/6 的语义正确率。没有足够证据给出统一的语义通过数量。

## 3. 具体错误类型

| 错误类型 | 真实反馈中观察到的问题 | 为什么重要 |
|---|---|---|
| 原文 `span`／字符索引错误 | 第一轮出现，第二轮归因题仍失败 | 破坏原始断言和生成节点的可核对映射；不能静默修补模型结果 |
| 任务结构遗漏 | 第一轮缺少根节点支持／反证任务；后来确认 M2 契约仅要求 **original 原子节点**拥有对应任务 | 必须区分真正的契约失败与提示词产生的冗余；AND/OR 根节点不应机械复制任务 |
| 伪子命题 | 把“信息未明确”建成投资断言；把“主营业务。”建成非断言节点 | 研究缺口不应冒充需要证明的财务主张 |
| 重复／冗余 | 状态题有重复组合节点及冗余根任务；归因题重复归因节点 | 容易产生不必要的研究工作和不透明的组合判断 |
| 因果逻辑错误 | 将“无法识别影响”混同于对因果主张的证伪 | **证据不足 ≠ 反证成立**，否则可能给出错误投资研究判断 |
| 预测表达缺失 | 因果题没有将尚未观察的未来结果独立建模 | 未来事件不能被提前判成实际事实，也不应被提前判为反对 |

以上均为开发对话中已报告的观察；**未收到模型完整输出文件，因此这里不贴“原文示例”或臆造逐条输出文本**。

## 4. 为什么保留人审，而不是自动修正

本项目采用以下准入分离：

```text
自然语言原主张
    ↓
DeepSeek：生成候选图、任务、变化条件
    ↓
M2：严格校验 Schema、span、逻辑依赖及任务契约
    ↓
研究者：审核原意、限定条件、AI 新增假设及竞争解释
    ↓
已确认版本 → 证据绑定与确定性判断
```

- 模型候选不能覆盖用户原句；额外推断标记 `suggestion`，不自动晋升为用户主张。
- JSON Schema 合法只证明结构，不能证明因果、归因、否定等语义正确。
- 缺材料、未来尚未观察、无法辨别因果应维持**无法验证**或需要重验，而不是强行判负。
- 失败输出保留原始记录供迭代核查；人工编辑是明确的用户动作，不把静默修复计为模型通过。
- DeepSeek 不直接修改 M1 的已核验数字、来源和未决冲突。

## 5. 当前结论与后续评测要求

**已证实：** DeepSeek 实际网络调用可执行；至少一轮返回了 3/3 可解析 JSON；修订后 3 个案例中有 2 个满足 M2 契约。

**尚未证实：** 通用陈述式投资命题的保义准确率、三类命题的稳定成功率、归因／因果高质量研究规划、模型真实部署表现和生产调用费用。样本数量过少，不能推广到任意公司或研究问题。

后续如要称“AI 命题自动拆解能力通过”，至少应增加有人工标注标准的覆盖集、记录每条原文与输出／模型标识／用量、分开计数 Schema 和语义指标，并覆盖否定、量词、比较期间、必要前提、因果识别与未来事件；在此之前应在产品中明确显示候选审核状态。

**声明：** 本报告不是证券投资建议，也不是对供应商模型总体质量的量化排名。
